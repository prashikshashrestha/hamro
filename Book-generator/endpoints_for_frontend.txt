================================================================================
                       BOOK GENERATOR BACKEND API ENDPOINTS
================================================================================
Base Server URL : http://127.0.0.1:8000
API Prefix      : http://127.0.0.1:8000/api/
Format          : JSON (application/json)

--------------------------------------------------------------------------------
1. BOOKS ENDPOINTS
--------------------------------------------------------------------------------
- GET    /api/books/
  List all books (returns paginated list using BookListSerializer).

- POST   /api/books/
  Create a new book.
  Payload Example:
  {
    "title": "The Clockwork Realm",
    "genre": "Fantasy",
    "premise": "A clockmaker finds a portal inside an ancient watch.",
    "book_type": "fiction",
    "target_word_count": 50000
  }

- GET    /api/books/{id}/
  Retrieve detailed information for a specific book (includes nested profiles,
  chapters, characters, plot points, etc.).

- PUT    /api/books/{id}/
  Update all fields of a book.

- PATCH  /api/books/{id}/
  Partial update of a book.

- DELETE /api/books/{id}/
  Delete a book.

- POST   /api/books/{id}/generate/
  Trigger AI generation pipeline for the book.
  Returns status 202 Accepted.

- GET    /api/books/{id}/summary/
  Retrieve full summary and high-level structure of the book.


--------------------------------------------------------------------------------
2. SERIES ENDPOINTS
--------------------------------------------------------------------------------
- GET    /api/series/            List all book series.
- POST   /api/series/            Create a new book series.
- GET    /api/series/{id}/       Retrieve details of a series.
- PUT    /api/series/{id}/       Update a series.
- PATCH  /api/series/{id}/       Partially update a series.
- DELETE /api/series/{id}/       Delete a series.


--------------------------------------------------------------------------------
3. CHARACTERS ENDPOINTS
--------------------------------------------------------------------------------
- GET    /api/characters/               List all characters (supports query filters: ?book={book_id}&role={role}).

- GET    /api/characters/{id}/          Retrieve character details.
- PUT    /api/characters/{id}/          Update character.
- PATCH  /api/characters/{id}/          Partially update character.
- DELETE /api/characters/{id}/          Delete character.


--------------------------------------------------------------------------------
4. CHAPTERS ENDPOINTS
--------------------------------------------------------------------------------
- GET    /api/chapters/                 List all chapters (supports query filters: ?book={book_id}&status={status}).
- POST   /api/chapters/                 Create a chapter.
- GET    /api/chapters/{id}/            Retrieve chapter details.
- PUT    /api/chapters/{id}/            Update chapter.
- PATCH  /api/chapters/{id}/            Partially update chapter.
- DELETE /api/chapters/{id}/            Delete chapter.
- POST   /api/chapters/{id}/revision/   Log a revision request / request AI polish for chapter.
  Payload Example:
  {
    "reason": "Make tone more suspenseful",
    "new_text": "Updated content..."
  }
